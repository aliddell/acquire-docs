\doxysubsection{Detailed Description}
The settings for a Zarr stream. 

This struct contains the settings for a Zarr stream, including the store path, custom metadata, S3 settings, chunk compression settings, dimension properties, whether to stream to multiple levels of detail, the pixel data type, and the Zarr format version. \begin{DoxyNote}{Note}
The store path can be a filesystem path or an S3 key prefix. For example, supplying an endpoint "{}s3\+://my-\/endpoint.\+com"{} and a bucket "{}my-\/bucket"{} with a store\+\_\+path of "{}my-\/dataset.\+zarr"{} will result in the store being written to "{}s3\+://my-\/endpoint.\+com/my-\/bucket/my-\/dataset.\+zarr"{}. 
\end{DoxyNote}
